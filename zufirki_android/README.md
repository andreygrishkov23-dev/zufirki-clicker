# Зуфирки для Android (Samsung)

Космический кликер «Зуфирки». Игра написана на HTML5 (`app/src/main/assets/index.html`),
а Android-приложение — это обёртка, которая открывает её на весь экран.
APK собирается автоматически на GitHub.

## Как получить .apk (через GitHub, бесплатно)

1. **Распакуйте архив.** В Finder нажмите `Cmd + Shift + .` (точка), чтобы показать
   скрытую папку `.github`. Она обязательно нужна: в ней лежит сборка.
2. **Создайте репозиторий.** Зайдите на github.com, нажмите `+` → `New repository`,
   назовите его `zufirki`, выберите **Public** и нажмите `Create repository`.
3. **Загрузите файлы.** На странице нового репозитория нажмите `uploading an existing file`
   и перетащите в окно **всё содержимое** папки `zufirki_android` (папки `.github`, `app`
   и файлы `build.gradle`, `settings.gradle`, `gradle.properties`, `README.md`).
   Нажмите `Commit changes`.
4. **Дождитесь сборки.** Откройте вкладку `Actions`. Если GitHub просит разрешить
   workflow, нажмите `I understand my workflows, go ahead and enable them`.
   Сборка `Build APK` занимает 3–6 минут, в конце появится зелёная галочка.
   Если запуск не начался сам, выберите `Build APK` → `Run workflow`.
5. **Скачайте APK.** На главной странице репозитория справа откройте `Releases`
   и скачайте файл `Zufirki.apk` из последней сборки.

Если сборка закончилась красным крестиком, откройте её, скопируйте текст ошибки
из упавшего шага и пришлите мне.

## Установка на Samsung
1. Скачайте `Zufirki.apk` на телефон (откройте страницу Releases в браузере телефона)
   или перешлите файл с компьютера, например себе в Telegram.
2. Откройте файл. Android спросит разрешение на установку из этого источника,
   разрешите его.
3. Если установка блокируется, отключите Auto Blocker: `Настройки` →
   `Безопасность и конфиденциальность` → `Auto Blocker`.
4. Если Google Play Protect показывает предупреждение о приложении без подписи Google,
   выберите `Всё равно установить`. Приложение подписано отладочным ключом, это нормально
   для своих сборок.

## Сохранение прогресса
Прогресс сохраняется на телефоне сам: после каждой покупки, раз в секунду во время игры
и при сворачивании приложения. После перезапуска он подхватывается. При удалении
приложения прогресс стирается.

## Сборка на своём компьютере (по желанию)
Откройте папку в Android Studio и выберите `Build` → `Build Bundle(s) / APK(s)` →
`Build APK(s)`. Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Яндекс Игры
Игра — один файл `app/src/main/assets/index.html`. Для Яндекс Игр упакуйте его в ZIP
так, чтобы `index.html` лежал в корне архива, и загрузите в консоль разработчика.
Перед публикацией подключите Яндекс SDK (`<script src="/sdk.js"></script>` и `YaGames.init()`).

## Что внутри
- `app/src/main/assets/index.html` — вся игра (логика, графика, магазин, сохранение)
- `app/src/main/java/ru/zufirki/clicker/MainActivity.java` — обёртка WebView
- `app/src/main/res/` — название приложения и иконка
- `.github/workflows/build-apk.yml` — автоматическая сборка APK
